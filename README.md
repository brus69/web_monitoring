# WebMon - Мониторинг изменений на сайтах

Консольная программа на Go для автоматического отслеживания изменений на веб-сайтах. Программа периодически проверяет указанные URL-адреса, анализирует содержимое страниц и выводит детальный отчет об изменениях.

## Возможности

- Поддержка нескольких форматов входных файлов: `.txt`, `.csv`, `sitemap.xml`
- Настраиваемый интервал проверки (в секундах)
- Ограничение количества одновременных запросов (параллелизм)
- Сохранение состояния в JSON-файл
- Детальный мониторинг: заголовок (title), описание (description) и текст страницы
- Цветной вывод изменений: 🟢 зеленый — добавлено, 🔴 красный зачеркнутый — удалено
- Табличный отчет с кодом ответа и датой проверки
- Работа в бесконечном цикле

## Установка

### Требования
- Go 1.22 или выше

### Сборка из исходного кода

```bash
git clone <repository-url>
cd web_monitoring
go build -o webmon .
```

После сборки исполняемый файл `webmon` будет создан в текущей директории.

## Использование

### Базовый запуск

```bash
./webmon --file urls.txt --interval 14400 --concurrency 10
```

### Параметры командной строки

| Флаг | Описание | По умолчанию |
|------|----------|--------------|
| `--file` | Путь к файлу со списком URL (обязательно) | - |
| `--interval` | Интервал проверки в секундах | `14400` (4 часа) |
| `--concurrency` | Максимальное количество одновременных запросов | `10` |
| `--state` | Путь к файлу состояния | `state.json` |

### Примеры запуска

```bash
# Проверка каждые 4 часа (14400 секунд), максимум 10 параллельных запросов
./webmon --file sites.csv --interval 14400 --concurrency 10

# Быстрая проверка каждые 10 секунд (для теста)
./webmon --file urls.txt --interval 10

# Использование файла состояния с нестандартным именем
./webmon --file urls.txt --state my_state.json

# Проверка sitemap.xml каждый час (3600 секунд)
./webmon --file sitemap.xml --interval 3600
```

## Форматы входных файлов

### Текстовый файл (.txt)
Один URL на строку:

```
https://example.com
https://google.com
https://github.com
```

### CSV файл (.csv)
Первый столбец должен содержать URL. Поддерживается заголовок (строки, содержащие "url" или "URL", пропускаются):

```csv
url
https://example.com
https://google.com
```

Или без заголовка:

```csv
https://example.com
https://google.com
```

### Sitemap XML (.xml)
Стандартный формат sitemap:

```xml
<?xml version="1.0" encoding="UTF-8"?>
<urlset xmlns="http://www.sitemaps.org/schemas/sitemap/0.9">
  <url>
    <loc>https://example.com</loc>
  </url>
  <url>
    <loc>https://example.com/about</loc>
  </url>
</urlset>
```

## Формат файла состояния (state.json)

Программа автоматически создает и обновляет файл состояния (по умолчанию `state.json`):

```json
{
  "pages": [
    {
      "url": "https://example.com",
      "content_hash": "fb91d75a6bb430787a61b0aec5e374f580030f2878e1613eab5ca6310f7bbb9a",
      "last_checked": "2026-04-30T09:00:47.011634+03:00",
      "status": "unchanged",
      "title": "Заголовок страницы",
      "description": "Описание страницы",
      "text_content": "Текст страницы..."
    }
  ]
}
```

### Поля состояния:
- `url` — адрес страницы
- `content_hash` — SHA-256 хеш содержимого страницы
- `last_checked` — время последней проверки
- `status` — статус: `new` (новая страница), `changed` (изменена), `unchanged` (не изменена)
- `title` — заголовок страницы (тег `<title>`)
- `description` — описание страницы (мета-тег `description`)
- `text_content` — извлеченный текст страницы

## Как это работает

1. При запуске программа читает список URL из указанного файла
2. Загружает предыдущее состояние из `state.json` (если файл существует)
3. Запускает бесконечный цикл проверки с заданным интервалом
4. В каждом цикле:
   - Загружает содержимое каждой страницы (с таймаутом 30 секунд)
   - Извлекает заголовок, описание и текст страницы
   - Сравнивает с предыдущим состоянием
   - Выводит детальный отчет об изменениях с цветовой индикацией
   - Сохраняет обновленное состояние в JSON-файл

## Вывод программы

После каждой проверки программа выводит детальный отчет:

```
Loaded 2 URLs

2024-01-15 12:00:00 | 200 | TITLE CHANGED
  Old: "Старый заголовок"
  New: "Новый заголовок"
  Diff: Новый Старый

2024-01-15 12:00:00 | 200 | TEXT CHANGED
  Diff (first 200 chars): добавленное слово удаленное...

2024-01-15 12:00:00 | 200 | unchanged
Check complete: 1 changed, 1 unchanged
```

Цвета в терминале:
- 🟢 **Зеленый** — добавленные слова
- 🔴 **Красный + ~~зачеркнутый~~** — удаленные слова

## Ограничения

- Таймаут HTTP-запроса: 30 секунд
- Используется только стандартная библиотека Go (нет внешних зависимостей)
- Программа работает в бесконечном цикле (для остановки используйте `Ctrl+C`)
- Для корректного отображения зачеркнутого текста требуется современный терминал (iTerm2, VSCode, Gnome Terminal)
