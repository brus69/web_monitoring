Фронтенд - личный кабинет с авторизацией(сделай авторизацию по логину admin пароль admin2) технологии react

в личном кабинете можно создовать проекты при нажатии на кнопку "Создать проект"
Проект можно редактировать или удалить


при создании проекта в первый шаг нужно загрузить urls которые будем отслеживать это можно сделать через форма модального окна выбор файла на пк

после загрузки файлов указывается какие данные будут отслеживаться title description content и т.д.

потом указывается тайминг отслеживания пусть будет в минутах

все результаты выводятся в фронтенде таблицей по 100 урлов на страницу потом идеёт пагинация

фронтенд и беккенд взоимодействуют по api
